# react-native-html-lite

Lightweight native HTML renderer for React Native: a dependency-free C++ HTML parser exposed as a Turbo Module, rendered with Text and View

## Installation


```sh
npm install react-native-html-lite
```


## Usage


```js
import { multiply } from 'react-native-html-lite';

// ...

const result = multiply(3, 7);
```
